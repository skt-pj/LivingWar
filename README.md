# LivingWar

NPCが自律して生活する世界で、勇者軍と魔王軍が継続的に戦うゲームを目指すプロジェクトです。

現在はWeb版の魔王軍側プロトタイプを実装しています。

## 起動

`index.html` をブラウザで開いてください。外部ライブラリ、ビルド、サーバーは不要です。

## 表示方針

- ゲーム画面: GBモード
  - 内部解像度 160×144
  - 4色のみ
    - `#9BBC0F`
    - `#8BAC0F`
    - `#306230`
    - `#0F380F`
  - ダンジョンは20×16マスを8pxタイルで表示
- 外側の操作UI: 通常のWeb表示

## 現在入っているもの

- 開始時に「勇者軍 / 魔王軍」を表示（勇者軍は未実装）
- 魔王軍を選ぶと 1F のダンジョン製作画面へ遷移
- 20×16 タイルの見下ろし型ダンジョン
- ピンチ操作によるダンジョン表示の拡大・縮小・位置調整
- 床 / 壁の編集
- 入口の配置
- 次の階への階段（出口）の配置
- 入口から出口まで必ず床で到達できるように壁配置を制約
- モンスター / 罠は通路判定の障害物にせず、入口・出口マスにも配置可能
- スライム / ゴブリンの配置
- トゲ罠の配置
- モンスターの徘徊テスト
- ブラウザ `localStorage` への設計保存 / 読込

## 暫定モンスター行動

- スライム: 現在方向を優先し、塞がっている場合は時計回りに候補を切り替える
- ゴブリン: 直進を優先し、塞がっている場合は右、左、後ろの順で候補を切り替える

## 未確定のため固定していないもの

- ドロップアイテム: `未設定`
- 進化条件: `未設定`
- 勇者の侵入 / 自動攻略
- 戦闘
- 罠ダメージ
- NPCBrain 接続

モンスター定義は `game.js` の `MONSTER_DEFS` にまとめています。

## 最終ロードマップ

NPCBrainを接続し、NPCが自律して生活・行動する世界を構築する。その世界の中で勇者軍と魔王軍がそれぞれ活動し、ダンジョン攻略・防衛・戦闘が継続的に発生する構成を目指す。
